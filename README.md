# ak-finccam/r-packages

R package repository for finccam forks and retained upstream binaries.

Install in R:
`
install.packages('Rblpapi', repos = c('https://ak-finccam.github.io/r-packages', 'https://cloud.r-project.org'))
`

Polars 1.15.0 is available for Windows R 4.5 and Ubuntu Noble x86-64 R 4.5.2. See the [build and update recipe](recipes/polars.md) for repository URLs, checksums, licenses and reproduction steps.
